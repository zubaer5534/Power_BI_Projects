## Smoking Health Risk Analysis

A Dashboard Guided by "@AnalysisWithEmmanuel" to identify,

This interactive healthcare analytics project showcases end-to-end data transformation and dynamic dashboard design using Power BI and Power Query. By structuring raw clinical and demographic datasets into a robust data model, the project leverages advanced DAX measures to evaluate patient outcomes, demographic patterns, and health risk trends.

The interactive dashboard features customized KPI cards, donut charts, ribbon charts, and button slicers to streamline navigation and present actionable health insights. Designed to translate complex hospital data into clear medical storytelling, this project demonstrates practical expertise in building portfolio-ready analytics solutions that support preventive care and data-driven healthcare decision-making.
